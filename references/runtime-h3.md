# H3 运行规则

## 模板优先级

1. 实际查看已确认首帧，再完整读取 [templates/h3-structure-reference.txt](templates/h3-structure-reference.txt)。
2. 把该文件当作严格结构模板，而非仅供风格参考。保留它的字段顺序、单镜头写法、场景和材质描述密度、逐段时间码、结尾状态、静态机位总结及完整声景；只把主题、首帧事实、动作细节、9:16 比例、总时长、略快且更丰富的动作编排，以及更响、更饱满的沉浸式 ASMR 声景适配为当前任务。
3. 不因节省 Token 缩写、概括、合并字段或省略细节。若本文件与低消耗规则冲突，以“完整复刻模板结构”为准。

## 英文版

严格按以下三个顶层字段及顺序输出，不加解释、模型参数或 Markdown 代码围栏：

```text
integrated_multimodal_description: [Shot 1] ...

overall_soundscape: ...

non_diegetic_music: N/A
```

`integrated_multimodal_description` 必须是与参考模板同等完整度的连续正文，并逐项包含：

1. `[Shot 1]`、live-action、photorealistic ASMR macro product video、one continuous uncut shot、9:16 portrait frame、精确 15 秒。
2. 锁定机位和角度；严格描述首帧中双手的数量、裸手、短自然指甲、托盘/背景、柔和顶前漫射光、高光、次表面散射及景深。
3. 完整描述主体的位置、尺寸、食物形状、数量、颜色层次、外皮/内芯结构、表面微纹理、黏性、弹性、延展性等。所有事实来自已确认图片，不更换道具或场景。
4. 从 `00:00.000` 的已确认首帧开始，用参考模板同等级的高密度时间码连续覆盖至 `00:15.000`：先快速完成起始展示和接触，再以约 0.4–0.8 秒粒度逐段推进；复杂拉伸、扭转或折叠段可用 0.8–1 秒。不得用一句话概括数秒动作，不得出现时间缺口、倒序或重叠。
5. 动作不能只重复按压。根据主体材质，从以下动作库中自然组合至少 8 类可见动作：指腹轻触、单指试压、双拇指对压、多指交替按压、侧向夹捏、局部抠起/剥离、掌根或指节压扁、向内聚拢、揉圆、对折、连续揉折、轻微扭转、短幅拉扯、宽幅拉伸、黏丝分离、回收叠放、挤出气泡、末段压合。至少安排 4 次力度、方向或手位变化，并包含“塌陷或破裂—剥离—揉折—拉伸—回收压合”的完整主链条；只选择符合当前主体物理性质的动作，不机械堆砌。
6. 每个时间段同时写清：左右手/手指的具体动作、主体空间方向和姿态变化、材料受到作用后的可见结果、仍保持完整的部分及与上段的连续关系。主要动作之间插入短促但清楚的二级动作，如指尖重新定位、边缘补捏、快速收拢、追加压痕或拉丝回收，使动作持续变化且保持连贯。
7. 明确最终压合后的主体状态；结尾保留与模板等义的静态相机总结：相机全程不动，所有视觉运动只来自连续手部操作和物理一致的材料形变。

## 动作节奏

- 整体采用比参考模板约快 10%–15% 的中等偏快 ASMR 节奏；动作紧凑、顺滑、有连续惯性，但不得表现为快放、抽动或突然跳变。
- 首帧静态展示控制在约 0.3 秒，随后立即接触和施压；不要让单个展示、等待或保持动作持续超过约 0.8 秒。
- 在 15 秒内保持高动作密度：每个主要动作后尽快衔接一个不同的小动作，例如指尖重新定位、拇指追加按压、边缘夹捏、外皮加速塌陷、短拉、回卷或快速收拢后立即揉折；避免连续多个时间段重复同一种按压，每个动作仍需写出完整可见的材料反馈。
- 使用 `promptly`、`with a smooth brisk motion`、`at a moderately quick pace`、`without pausing` 等适度加速表达；减少反复使用 `very slowly`、`long hold` 或长时间静止。
- 最终压合后的停留约 0.3–0.5 秒，只用于看清结束状态。不得为了加速删掉破裂、揉折、拉伸或回收压合阶段。

## ASMR 声景强度与沉浸感

`overall_soundscape` 不得简写为声音词列表，必须按模板写成完整英文段落，并满足：

- 声音采用近距离、高灵敏度、双耳或宽立体声 ASMR 收音质感；主体声音位于前景，明显高于极弱室内底噪，听感比参考模板更响、更饱满、更贴耳，但保持干净，不削波、爆音、失真或过度压缩。
- 严格依照时间轴为每类动作匹配可分辨的声音：皮肤轻触和指腹摩擦、柔软闷压、湿润挤压、外皮细裂或脆响、气泡密集爆破、黏性剥离、拉丝细响、宽幅弹性拉扯、折叠拍合、揉捏咕叽、末段厚实压合。不得只用 `squish`、`pop` 等少量词反复概括。
- 每个主要动作至少有一个同步主声音，关键破裂、剥离、拉伸和折叠可叠加 2–3 层互不遮蔽的材质细声；声音触发随动作密度同步增加，并随左右手位置产生细微左右声像移动，形成包围式近场沉浸感。
- 保留合理动态：轻触清晰、重压更厚、更响，破裂和气泡音短促突出，拉丝与拉伸声有连续尾音；整体响度增强但不让所有声音同样大。
- 写明无讲话、无呼吸抢声、无环境杂音；只有极弱室内底噪。`non_diegetic_music` 仍为 `N/A`。

`non_diegetic_music` 必须为 `N/A`。
