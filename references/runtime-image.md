# 首帧运行规则

1. 完整读取 [templates/image-style-reference.txt](templates/image-style-reference.txt)。学习美学骨架和十大维度，不照搬示例的葡萄簇、粉紫渐变、3:4 比例或 Midjourney 参数。
2. 写可直接用于图像模型的英文首帧提示词，必须包含：
   - 选定食物是唯一主题，形态一眼可辨；呈现可捏、柔软、半透明或细腻糯感，材质符合该食物，不强制葡萄球体。
   - 微距产品摄影、中心竖构图、静态首帧、浅景深、柔和漫射光、干净无标记背景、治愈解压氛围、写实微纹理。
   - 适合后续动作连续性的手部起始姿态；手部解剖自然、短自然指甲、无首饰；默认无脸和身体。
   - `9:16 portrait composition`、`2160 × 3840 4K`；主体和关键手部不贴边，为视频动作留空间。
   - 无文字、水印、Logo、包装、多余/畸形手指、重复主体或杂乱道具。
3. 先以 UTF-8 保存 `01-首帧图片提示词-v01.txt`；修改时依次用 `v02`、`v03`，不得覆盖。
4. 调用可用的图像生成工具直接生图，工具调用再次强调 9:16 和 4K。若不支持精确像素，要求原生竖版最高质量；不得用横图裁切冒充，不得用 Python 或普通绘图库代替生成模型。
5. 将原图保存为 `02-首帧-v01.png` 或工具实际无损格式；重做时递增版本。
6. 展示图片并只问：“这张首帧是否确认？如果不满意，请告诉我需要调整什么。”然后停止。未确认不得生成 H3 提示词。
