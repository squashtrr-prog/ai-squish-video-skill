# 发布与归档规则

1. 根据已确认视频提示词写一段简短、有感官画面的中文小红书文案，不虚构视频中没有的动作。
2. 生成 6–10 个相关标签，必须包含主题词及解压/ASMR 类词，不蹭无关热点。
3. 将 `04-小红书发布文案.txt` 以 UTF-8 保存，格式固定：

```text
主题：
最终标题：

备选标题：
1. ...
2. ...
3. ...
4. ...
5. ...

文案：

标签：
#标签1 #标签2 ...
```

4. 更新本次目录中的 `run.json`，将 `state` 设为 `COMPLETE`，并记录最终标题及已确认文件名；同时保存 `00-制作记录.txt`，记录创建时间、主题、已确认首帧文件名、已确认首帧提示词文件名、已确认 H3 英文和中文文件名、最终标题和状态 `COMPLETE`。不记录用户隐私或工具内部信息。
5. 递归核查本次输出目录，必须包含：
   - 已确认首帧原图；
   - 对应首帧图片提示词 TXT；
   - 已确认 H3 英文和中文视频提示词 TXT；
   - 含最终标题、5 个备选标题、文案和标签的 TXT；
   - 制作记录 TXT。
6. 缺项时补齐后再报告完成。
